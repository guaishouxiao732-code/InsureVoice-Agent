# 智能业务助手网页

该网页直接接入本项目的 Qwen3-4B、保险资料 RAG、SQLite 上下文、SenseVoice ASR 和 CosyVoice TTS。支持电脑和手机自适应、快/慢模式、流式文字、录完再发送、停止回答、历史会话和 RAG 证据查看。

回答显示使用本地化的 Marked、DOMPurify 和 KaTeX，可安全渲染 Markdown、行内/独立 LaTeX 公式、列表、引用和代码块，不依赖浏览器访问外部 CDN。

## 短期公网测试

```bash
source "$(conda info --base)/etc/profile.d/conda.sh"
conda activate qwen3-vl
cd /path/to/InsureVoice-Agent/http
python public.py
```

启动后终端会显示：

- `https://....trycloudflare.com` 临时公网地址；
- 保存在本机 `http/.web.env` 中的固定访问密码。

把地址和密码发给上海的测试用户。合肥主机、网页进程和 Tunnel 必须持续运行。按 `Ctrl+C` 会立即中止访问；下次启动的临时网址会变化，但密码保持不变。

如果想在某次启动时临时覆盖固定密码：

```bash
WEB_PASSWORD='你自己的测试密码' python public.py
```

`.web.env` 已被 `.gitignore` 排除，不应上传、公开或发送给无关人员。

## 运行资源

- Qwen：GPU 1
- CosyVoice：GPU 0
- SenseVoice ASR 和 BGE 检索：CPU
- 网页会话数据库：`data/web_conversations.sqlite3`
- 录音上限：30 秒 / 12 MB

## 默认录音交互

默认语音输入为“录完再发送”：点击麦克风开始录音，再次点击结束并发送；录音期间停顿不自动提交，结束后自动识别为文字并交给助手回答，无需再点发送。录音到30秒时保护停止并发送。
开始录音的点击会立即停止正在播放的旧语音，并取消尚未完成的旧回答或语音合成，避免旧音频在录音期间再次响起；这次录音仍要再次点击才会发送。

按钮随状态显示“开始录音／结束录音并发送”，首页大按钮显示“点击开始录音／点击结束并发送”。现在只保留录完再发送，设置中的连续语音选项已删除，旧的模式偏好不再生效。录音期间切换会话、发送文字、离开页面或连接断开会取消录音，丢弃音频并释放麦克风，不自动提交。

更新后强制刷新浏览器（电脑按 `Ctrl+Shift+R`），第一次使用允许麦克风权限。远程设备必须使用 HTTPS 公网地址；本机可使用 localhost。

## 自动快慢协同

默认模式为“自动协同”，保留手动快／慢调试入口。快路径整理常见意图、维护用户明确表述的条件，缺少必要信息时先问一个问题；条件补充后交给 RAG 和共享 Qwen 完成简单回答或慢路径分析。不会同时输出两份答案，也不会以占位话术刷首响。检索证据不足仍直接提示待人工，不使用模型知识补充。

验收可依次说／输入“年缴多少钱”“30”“有社保”，应先询问年龄、再询问社保，最后检索年缴费率；随后说“不是我，是我父亲，65岁”，必须重新询问父亲社保，而不是沿用原条件。复杂示例“有高血压，住院能赔吗”应先区分投保和理赔，再根据补充信息进入慢路径；回答头部、历史及依据面板显示真实路径和用户条件。

这是规则型共享调度器，不是新增两个模型并行生成。条件版本随本会话轮次更新，新消息和停止按钮沿用统一取消。录音使用开始录音时的思考模式和语速。完整产品规则、全语义条件抽取和逐项证据校验仍待完善，比赛指标尚未因此得到认证；启动方式与已有密码不变。

## 连续语音已移除

不再边录边上传、停顿自动发送、临时转写、预检索或语音自动插话。前端 PCM AudioWorklet 已删除，后端拒绝 `listen_start`、`listen_stop` 和二进制连续音频帧，旧页面应刷新后使用录完再发送。ASR/TTS 模型及历史数据库保留，网页不再调用 VAD 工具。

“停止”按钮仍可取消生成并清空待播音频；提交新的录音或文字也可取消上一轮。取消后不能再将当前页面视为全双工自然打断演示，此版本不满足命题中的自然语音打断要求。

验收：点击录音后说话并停顿，确认没有上传或自动提问；再次点击后才出现识别文字、回答及语音。录音中切换会话应丢弃录音，不在新会话收到旧问题。重启服务后强制刷新，设置中不应出现连续语音选项。

首响应从点击结束并发送到首次实际听到音频计时，另保留用户说完到音频首播的原始时长用于比赛口径；服务端首批音频耗时不能替代浏览器实际播放耗时。

## 文字提速、来源展示与手动停止

文字读取/保存与 TTS 合成使用独立线程，文字不再等待每段语音合成；语音段按原顺序处理，保留约1秒音频预缓冲，不通过取消缓冲换取首响。WebSocket 单独发送 `text_done`，可先查看完整文字及依据，再等待语音合成和播放。元数据新增 `voice.text_completed_ms`，区分文字完成与音频输出；较长答案的完整播报仍可能超过10秒。

普通问题提示尽量80—120字、复杂问题200—300字，保留必要条件和安全提示；用户要求详细说明时允许展开，不额外缩小 token 上限强行截断。来源、文件位置与实际注入模型的片段由检索元数据提供给“回答依据”，不由模型生成；正文不追加检索来源或诊断，历史正文保持原样。这是检索资料展示，不是逐条结论已验证。

“查看回答依据”会在来源标题和完整片段中自动高亮当前问题里与资料相同的关键词；也可以在面板搜索框输入一个或多个词（空格、逗号分隔），点“下一处”逐个定位。清空搜索框恢复自动高亮。高亮只在浏览器展示层完成，不改变检索结果、相似度、回答正文或资料本身；字面匹配不代表条款已核验。没有来源时不显示搜索框。

“停止”在生成、合成及浏览器音频队列未播放结束时保留，历史回答手动播放也可停止。点击立即清空音频、阻止旧轮次文字和音频重新进入，并请求后台取消；服务端立即确认，后台等待当前 GPU/ASR/TTS 操作安全收尾。不能强制中断正在执行的 CUDA 内核，下一次请求可能短暂等待资源释放。识别期间停止后，识别结果不能再触发模型回答。

可选真实浏览器测试：预热独立测试服务后执行 `TEST_WEB_URL=http://127.0.0.1:8011 python http/test_speed_stop_browser.py`，覆盖文字先完成、正文无来源、依据来源保留、播报结束前停止、历史重播停止、生成中停止及随后正常提问。需要 Playwright/Chromium，测试只删除它新建的会话。

依据高亮可运行 `python http/test_evidence_highlight.py`，启动临时本机静态服务并用 Chromium 检查自动高亮、手动搜索、跳转、长片段、手机/桌面布局及资料文本的安全呈现，不加载模型或修改会话。

## 证据不足时待人工处理

检索证据不足时直接输出“根据当前保险资料无法确认该问题，需转人工处理。目前为待人工处理状态，尚未接入人工客服。”，不调用 Qwen 补充业务答案。文字和语音采用相同提示；会话元数据保存 `knowledge_mode=handoff` 和 `handoff.status=pending`，回答及历史记录显示“待人工处理（尚未接入人工客服）”。回答依据中可查看未采用的候选片段，但这些不是支持结论的引用。

这是第一版的待人工提示和会话标记，不是客服接通或已提交的工单。尚未新增人工接待台，不会显示转接成功。已有历史不会重写，旧模型知识补充内容会标明是旧规则记录。检索充分仍走原有基于资料的回答流程；本次未增加逐项证据核验或条件完整性判断，不能据此宣称所有不确定回答都已被拦截。

验收：问一个资料外的问题，例如“Python 列表和元组有什么区别？”，检查文字提示、语音播报、待人工标记和回答依据；刷新页面确认标记保留，再问资料内的问题确认正常引用回答不受影响。

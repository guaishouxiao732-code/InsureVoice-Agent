# 语音插话链路验收报告

## 一、验收结论

本轮共执行40次语音插话链路测试。每轮均同时满足旧语音停止、新问题正确识别、自动生成正确回答和上下文保持四项要求，整轮成功40次，成功率为100%，达到“成功率不低于95%”的验收标准。

本结论适用于当前网页的交互方式：Agent播报过程中，用户点击录音键开始插话，再次点击结束录音并发送。测试使用真实Chromium浏览器、当前公网隧道和模拟麦克风音频，不等同于上海设备上的真人物理麦克风测试，也不代表免点击、直接开口触发的全双工插话已经通过验收。

## 二、测试时间与环境

- 测试日期：2026年10月14日
- 被测系统：当前运行中的智能业务助手网页
- 浏览器：Chromium，由Playwright驱动
- 访问链路：当前Cloudflare公网临时隧道
- 语音输入：通过浏览器MediaRecorder采集的模拟麦克风音频
- ASR：项目当前配置的本地语音识别服务
- TTS：项目当前配置的CosyVoice中文女声服务
- 测试并发：单用户、逐轮顺序执行
- 页面或项目代码改动：无
- 浏览器页面错误：0次

## 三、测试场景

每轮使用独立测试会话，执行以下步骤：

1. 先输入“我30岁有社保，年缴基础费率是多少？”，建立年龄、社保和缴费方式上下文。
2. 确认种子问题回答包含318元。
3. 播放一段旧回答，并确认浏览器检测到非静音音频。
4. 在旧回答播放期间点击录音键，触发旧回答停止并开始录音。
5. 播放模拟麦克风输入：“改成35岁，年缴基础费率是多少？”
6. 再次点击录音键，结束录音并发送。
7. 检查ASR结果、自动回答和结构化上下文。
8. 删除该测试会话，避免不同轮次互相影响。

## 四、单轮通过标准

只有以下四项全部通过，该轮才记为成功：

| 验收项 | 判定标准 |
|---|---|
| 旧语音停止 | 开始录音后250毫秒，旧语音RMS低于0.0001，活动音频源为0，待播队列为0，并且浏览器执行过停止操作 |
| 新问题识别 | ASR结果同时包含“35岁”和“年缴” |
| 自动回答 | 系统自动生成新回答，且回答包含正确费率423元 |
| 上下文保持 | 年龄更新为35岁；沿用前文“有社保”；缴费方式保持年缴 |

种子条件建立失败、任一子项失败或测试过程报错，均判定该轮失败，不以其他子项通过抵消。

## 七、结果解释与验收边界

本轮数据能够证明：在当前“点击录音开始插话、再次点击结束并发送”的操作下，浏览器能够停止旧语音，ASR能够识别新的完整录音，系统能够自动生成新回答，并能在新回答中沿用或更新已有会话条件。

本轮数据不能单独证明以下事项：

- 用户不点击任何按钮、直接开口即可触发打断；
- 上海真实网络条件下的插话成功率；
- 不同真人口音、音量、语速和环境噪声下的ASR成功率；
- 40个不同问题和不同插话时机下的泛化成功率；
- 手机扬声器回声、弱网和麦克风权限异常情况下的稳定性。

因此，对外表述应为：“当前点击录音式语音插话链路自动化测试40/40通过。”不应表述为“免点击全双工真人语音插话已经完成最终验收”。最终比赛验收仍建议在上海设备上使用真人物理麦克风，覆盖不同问题、不同插话位置和真实网络环境复测。

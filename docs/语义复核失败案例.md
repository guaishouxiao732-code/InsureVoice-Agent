# 语义复核记录与剩余验收边界

复核对象为真实网页 WebSocket 输出的快/慢思考题。检查重点是整段答案、责任适用范围、医保条件、免责例外及证据不足时的分流，而不是只检查首句或数字。完整题库见[快慢思考验收题库.md](快慢思考验收题库.md)。

## 本轮发现并修复

| 问题 | 修正方式 | 回归验证 |
|---|---|---|
| 特定药品的耐药、基因检测等免责条件被套用到重大疾病外购药械责任 | PDF免责资料按括号条款和子项切分并携带责任范围；特定药品条件不再跨责任召回 | 慢题Q19、Q44、Q47、Q48；RAG单元测试 |
| 300万与600万、不同住院责任是否同因等关系从分项数字/相邻条款推断 | 只有来源明确陈述关系时才生成；否则返回待人工处理 | 慢题Q16、Q92；关系边界单元测试 |
| 有医保身份但未按该身份结算被简写成所有“未走医保”都按60% | 生成时保留“以基本医保/公费医疗身份参保，但未以该身份就诊并结算”的完整前提；门急诊组合题使用来源确定性答复 | 慢题Q1、Q8、Q10、Q13、Q17、Q23；医保条件单元测试 |
| 被保险人年龄范围检索遗漏，生成错误年龄换算 | 将来源中的30天至70周岁与投保人18周岁及以上分别引用，不把年龄段换算成日期 | 慢题Q71、Q72；定向RAG回归 |
| 医院“普通部”条件被推广到所有公立医院，或混入特需责任 | 按责任分别回答，只把普通部限定用于来源指定的民营/特需机构；其他医院名单缺失时转人工 | 慢题Q7、Q15、Q88；医院范围回归 |
| 免责条款漏掉例外或把“未经科学/医学认可”扩大为所有试验治疗 | 确定性答复保留牙科意外例外，并明确试验性/研究性治疗仅在未经科学或医学认可时属于所列免责 | 慢题Q81、Q83、Q85、Q86；定向RAG回归 |
| 知识库只引用“释义二十七”但未收录合同正文，模型用邻近免责条款猜外购药械条件 | 明确当前资料无法确认，建议人工核实或查阅合同正文 | 慢题Q19、Q45、Q90；证据不足路由回归 |
| 独立改写题把“没有基本医保”“月付”识别为条件缺失 | 补充否定社保表达与缴费方式的同义识别，仍按已核对费率表取值 | 独立改写题Q1；条件识别单元测试 |
| 独立改写题把“有医保但没用医保结算”错答成仍按100% | 仅在检索到本责任完整医保前提及60%条款时给出限定答复 | 独立改写题Q3；RAG单元测试 |
| 境外质子治疗、超30天处方和牙科意外例外被当成缺个案条件追问或过度承诺 | 将抽象条款范围询问与真实个案分开；明确境外地域和超额处方边界，牙科只说明免责例外、不承诺获赔 | 独立改写题Q14、Q15、Q19；路由及RAG单元测试 |
| 高血压个案询问“能否保证承保”却追问年龄；指定医院完整名单未形成待人工状态 | 无正式核保结论或完整医院名单时直接待人工处理，明确尚未接通人工 | 独立改写题Q9、Q18；路由单元测试 |
| 地域范围的通用问题被写成针对“加拿大医院”的回答 | 改为只说明中国大陆及港澳台/境外范围，不附加用户未提及国家 | 固定慢题Q37；RAG单元测试 |

## 最新验收结果

- 快思考100题：最终代码下100/100自动事实与来源检查通过，完整回答p95约2.63秒。
- 慢思考100题：最终代码下100/100自动检查通过，完整回答p95约4.70秒；超出知识库证据或关系未明的题目以正确转人工计入。
- 独立改写20题：完整答案逐条复核20/20符合预期；初测至少6题实质错误、另1题未按要求形成待人工状态。该小样本不能证明所有未来问题的准确率。
- 浏览器实际停止操作：语音修复后复测100/100通过，其中80次先检测到播放信号再停止；停止后音频为静音，队列和生成状态清空。中断后上下文恢复检查通过。
- 语音：修复后另生成20段实音频，全部无削波，尾部相对响度差为−2.05至+0.83dB，首次出声p95约1.20秒，预计播放断流为0。用户指出的旧样本16逐字卡顿，经动态混合合成修复后由用户复听确认连贯且“一万元”清楚；其他语音未逐条人工试听，详见[验收总结](快慢思考与语音验收总结.md)。

自动检查100/100只说明当前固定题库和评分标准下通过，不等价于对任意新问题的普遍准确率保证。特别是个案核保、理赔结论、合同未收录条款和来源未说明的关系，系统应继续转人工，不应补充模型常识。
